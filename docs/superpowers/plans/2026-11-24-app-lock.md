# App Lock (Issue #110 & #157) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add full-window App Lock (`Pin4` auto-submit 4-digit PIN or 4–32 char `Custom` passcode) with cold-start, Linux close-to-tray, sleep/idle watchdog, and `Ctrl+L` / top title-bar quick-lock triggers, locked notification masking, VoIP call viewport isolation, and safe multi-account forgot-passcode sign-out to `ctdozlite`.

**Architecture:** A standalone non-GUI core module (`src/app_lock.rs`) handles PBKDF2-HMAC-SHA256 hashing, persisted brute-force cooldowns, sleep/idle classification, and notification masking, backed by a private `0600` atomic file `app_lock.json`. In `src/gui.rs`, `ZaloGuiApp::new` locks at frame 0 before any workspace render, `update_frame()` renders a dedicated lock module (`src/gui/app_lock_ui.rs`) instead of `render_chat_workspace()`, and `src/gui/worker.rs` runs a 5-second wall-clock sleep watchdog alongside `WorkerCmd::ForgetLockAndSignOutAll`.

**Tech Stack:** Rust 2021, `eframe`/`egui` 0.29, `tokio` 1, `sha2` 0.10, `getrandom` 0.3 (`getrandom::fill`), `base64` 0.22, `serde`/`serde_json` 1 (zero new crates; unit tests use RAII temp dirs under `std::env::temp_dir()`).

**Spec:** `docs/superpowers/specs/2026-11-23-app-lock-design.md`

## Global Constraints

- **Zero new Cargo dependencies:** Only use existing crates in `Cargo.toml` (`sha2 = "0.10"`, `getrandom = "0.3"` via `getrandom::fill`, `base64 = "0.22"`, `serde`, `serde_json`, `anyhow`, `tokio`, `eframe`/`egui`).
- **Cryptography:** PBKDF2-HMAC-SHA256 (`100_000` iterations, 16-byte CSPRNG salt via `getrandom::fill`, constant-time hash comparison); enforce `MIN_ITERATIONS = 10_000` on load.
- **Private atomic storage & zero plaintext leaks:** Persist `AppLockConfig` to `app_lock.json` via `crate::data_dir::write_private_atomic` (`0600` on Unix). Never persist or log plaintext passcodes (including `--dev` / `logger.rs`).
- **Persisted brute-force cooldown:** 5 consecutive wrong attempts lock unlock/verify inputs for 30 seconds; persist `failed_attempts` and `lockout_until_unix` (`i64`, `crate::login::unix_now()`) in `app_lock.json` and reset both to `0` on success, change, or disable.
- **Repository invariants (`scripts/check_invariants.py`, `R1`–`R8`):** Zero `.unwrap()` / `.expect()` in GUI production lines (`R1`); guarded `.clamp(min, max)` (`R2`); add `src/app_lock.rs` to `STRICT_NON_GUI_MODULES` (`R3`); zero `thread::sleep` or `TODO/FIXME/HACK` comments (`R4`); add `app_lock.json` to `.gitignore` and `R5` `forbidden_re` (`R5`); use `///` doc comments instead of regular `//` comments in new production code (`MAX_REGULAR_COMMENTS = 1430`, `R6`); zero new `std::time::Instant::now()` calls in `GUI_FILES` (`MAX_GUI_MANUAL_TIMERS = 31`, `R7`); never call `os_notify` from Windows GUI code (`R8`).
- **Windows build constraint:** Run every `cargo test` / `cargo clippy` / `cargo build` command with `-j 1` to avoid Windows page-file exhaustion (`os error 1455`).
- **Design & copy fidelity:** Style all new UI using `ThemePalette` tokens and `lucide` icons (`lucide::LOCK`) per `docs/DESIGN.md`; keep exact Vietnamese copy and scope boundaries (no SQLite encryption, no Windows/macOS tray, no per-account passcodes, no OS biometrics, no headless CLI/TUI/MCP/REST lock).

## Review Focus

1. **Corrupted or downgraded `app_lock.json` on startup** (truncated JSON, invalid Base64, `iterations < 10_000`, or unknown `version`): `AppLockConfig::load_from_path` returns `Err` instead of panicking or silently unlocking, and startup fails closed into the recovery lock screen whenever saved credentials exist — pinned by `load_corrupted_or_low_iteration_config_fails_closed` (Task 1) and `startup_lock_state_fails_closed_on_corrupted_config` (Task 3).
2. **System clock rollback / NTP step backwards** during lockout or sleep watchdog: negative wall-clock deltas never false-trigger sleep lock, and `remaining_lockout_secs` clamps to `0..=LOCKOUT_SECS` (`30`) so a clock jump backward cannot trap the user in a multi-hour lockout — pinned by `clock_rollback_does_not_trigger_sleep_or_extend_lockout` (Task 1).
3. **Unicode multi-byte chars & whitespace in `Custom` vs non-ASCII digits in `Pin4`:** `Pin4` rejects non-ASCII Unicode digits (`"١٢٣٤"`, `"１２３４"`) and accepts only 4 ASCII digits; `Custom` validates by `.chars().count()` in `4..=32` and preserves leading/trailing whitespace verbatim — pinned by `pin4_rejects_non_ascii_digits_and_custom_counts_unicode_chars` (Task 1).
4. **Locked window still OS-focused when active-thread messages/reactions arrive:** `effective_window_focused` must return `false` when `app_locked == true` so arriving messages do not silently mark the currently open chat as read, while `render_custom_title_bar` hides `user_name` — pinned by `effective_window_focused_is_false_while_locked` (Task 3) and `locked_popup_and_notification_masking_invariants` (Task 4).
5. **Multi-account "Quên mã khoá? Đăng xuất" deletion boundary:** `wipe_all_saved_session_credentials_in` deletes `session.json`, `app_lock.json`, and all `accounts/<uin>.json` credential snapshots while strictly preserving `accounts/*_threads.json`, `accounts/*_history.db*`, and `accounts/<uin>/` — pinned by `wipe_all_saved_session_credentials_preserves_history_and_threads` (Task 2).

#[test]
fn lockout_persists_across_reload_and_unlock_resets_counter() {
    let dir = TempDir::new("app_lock_cooldown");
    let path = dir.path().join(APP_LOCK_FILE);
    let mut cfg = AppLockConfig::create_enabled(PasscodeMode::Pin4, "2580").unwrap();
    cfg.save_to_path(&path).unwrap();

    for expected_rem in (1..MAX_FAILED_ATTEMPTS).rev() {
        assert_eq!(
            cfg.verify_attempt("0000", 10_000),
            VerifyOutcome::Wrong { remaining_attempts: expected_rem }
        );
    }
    assert_eq!(
        cfg.verify_attempt("0000", 10_000),
        VerifyOutcome::LockedOut { remaining_secs: LOCKOUT_SECS }
    );
    cfg.save_to_path(&path).unwrap();

    let mut reloaded = AppLockConfig::load_from_path(&path).unwrap().unwrap();
    assert_eq!(reloaded.remaining_lockout_secs(10_010), 20);
    assert_eq!(
        reloaded.verify_attempt("2580", 10_010),
        VerifyOutcome::LockedOut { remaining_secs: 20 }
    );
    assert_eq!(reloaded.verify_attempt("2580", 10_030), VerifyOutcome::Unlocked);
    assert_eq!(reloaded.failed_attempts, 0);
    assert_eq!(reloaded.lockout_until_unix, 0);
}
